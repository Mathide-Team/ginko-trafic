# Journal des versions

## 0.1.0 — 18/10/2026

- Version initiale : infos trafic et temps d'attente du réseau Ginko
  (Besançon) via l'API open data (clé gratuite requise).
- Binary sensor « perturbation » par ligne suivie, avec état
  (normal / information / perturbation prévue / en cours /
  circulation interrompue) et messages associés.
- Capteur « prochain passage » par abonnement arrêt + ligne + sens :
  minutes d'attente, destination, fiabilité temps réel, horaire
  textuel et affluence en attributs.
- Configuration : clé API, choix des lignes suivies ; abonnements
  arrêt/ligne/sens ajoutables et supprimables dans les options.
